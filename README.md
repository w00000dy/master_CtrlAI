# 🛡️ CtrlAI

Welcome to **CtrlAI**!

**CtrlAI** is an evaluation framework and proof-of-concept application developed to systematically measure the capabilities of Large Language Models in Compliance Engineering.

Specifically, the application provides a structured pipeline to investigate how well LLMs can automate the *Translation of Regulatory Requirements*. This process involves turning abstract legal texts, such as the EU Cyber Resilience Act, into concrete and actionable technical controls. Furthermore, the application allows for a detailed benchmarking of their performance against established baselines.

## 🌟 Features

- **Document Management**: Import and manage your legal documents.
- **Technical Guidelines**: Import technical guidelines and automatically extract their controls.
- **AI Control Generation**: Use AI to automatically generate compliance controls based on your legal documents.
- **Control Mapping**: Add, review, and map specific controls to document paragraphs.
- **AI Benchmarking**: Run tests and evaluate the controls generated by the LLM, including detailed result analysis.
- **Interactive UI**: Easily review benchmark results, edit mappings, and manage application settings.

## 🛠️ Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Start the development server:**
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser!
